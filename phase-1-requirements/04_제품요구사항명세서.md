# 04. 제품요구사항명세서(PRD)

- 기준일: 2026-08-25
- 상태: Draft v0.1
- 근거: 제공된 특허업무/기술특허 관리 가이드 및 Phase 문서 작성 가이드

## 2. 목적

## 3. 범위

## 공통 사전

### 역할
| 코드 | 역할 | 주요 권한 |
|---|---|---|
| ROLE-RND | R&D/설계자 | Feature/설계안/Evidence 등록, 회피설계 수행 |
| ROLE-PM | 제품/프로젝트 관리자 | 프로젝트·Gate·일정·범위 관리 |
| ROLE-IP | IP 담당 | 검색, 특허 선별, Claim Chart, Risk 평가 |
| ROLE-LEGAL | 법무/변리사 | 법률 검토, Critical/High 승인 |
| ROLE-QA | 시험/품질 | 시제품·시험 Evidence, 변경 영향 검증 |
| ROLE-EXEC | 의사결정자 | 출시/라이선스/중단 등 최종 Business Decision |
| ROLE-ADMIN | 시스템 관리자 | 기준정보·권한·연동·감사 설정 |

### 핵심 상태값
- Project: DRAFT → ACTIVE → ON_HOLD → CLOSED
- Patent Review: CANDIDATE → SCREENED → CLAIM_ANALYSIS → LEGAL_REVIEW → DECIDED → MONITORING
- Risk: CRITICAL / HIGH / MEDIUM / LOW / CLEARED
- Gate: NOT_STARTED / IN_REVIEW / PASSED / CONDITIONAL / REJECTED
- Decision: DESIGN_AROUND / LICENSE / INVALIDITY_REVIEW / ACCEPT / STOP / MONITOR

## 5. 제품 비전
**'특허 검토 문서 저장소'가 아니라 '설계 의사결정과 FTO 증적을 연결하는 개발 Gate 운영체계'**를 만든다.

### 페르소나/Jobs
| 사용자 | 핵심 Job |
|---|---|
| R&D 설계자 | 위험 청구항을 이해하고 안전한 대체 설계를 검증 |
| IP 담당 | 검색→선별→Claim Chart→Risk 평가를 빠르고 재현 가능하게 수행 |
| PM | Gate 미완료/고위험 때문에 출시가 늦어지지 않도록 선제 관리 |
| 법무/변리사 | 중요한 이슈에만 집중하고 판단 근거/버전을 추적 |
| QA | 시제품/시험 결과가 회피설계 의도와 일치하는지 검증 |
| 경영진 | 국가/제품별 FTO 리스크와 의사결정 비용을 파악 |

### MVP(P1)
1. 프로젝트/Scope/Gate
2. Feature Tree/설계 Rev
3. Patent/Family/Legal Status 수동·CSV Import
4. Claim Chart
5. Risk/Decision
6. Evidence
7. Approval/RBAC/Audit
8. Dashboard

### P2
- 외부 Patent DB API
- PLM ECO/ECN Trigger
- Watch/Alert
- AI/RAG Copilot

### P3
- 포트폴리오 전략/발명신고
- 라이선스/계약 확장
- 고급 특허맵/네트워크 분석

### 제품 성공 조건
- 사용자가 한 프로젝트에서 “왜 이 Gate가 통과됐는지”를 Evidence까지 3클릭 이내 추적
- Critical/High 이슈를 프로젝트 대시보드에서 즉시 식별
- 설계 Rev 변경 시 연관 Claim Chart/Risk 자동 표시
