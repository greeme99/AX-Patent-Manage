# 01. 프로젝트 개요서

## 1. 문서 정보
- 프로젝트: 설계특허관리 웹앱 (Design Patent/FTO Management Platform)
- 기준일: 2026-08-25
- 상태: Draft v0.1
- 근거: 제공된 특허업무/기술특허 관리 가이드 및 Phase 문서 작성 가이드

## 2. 목적
신제품·부품 개발 과정에서 특허 검색, Claim 분석, 회피설계, Evidence, Gate 승인, 출시 후 모니터링까지 하나의 추적 가능한 업무체계로 통합하는 프로젝트를 정의한다.

## 3. 범위
설계특허관리 웹앱

## 5. 프로젝트 정의
**한 줄 정의:** 설계변경과 특허 리스크를 연결하여 개발 초기부터 출시·양산까지 FTO 의사결정을 추적하는 제조 R&D/IP 협업 웹앱.

### 문제
- 특허 검토가 문서/메일/개인 Excel로 분산되어 설계 Rev와 특허 판단의 연결이 끊긴다.
- 출시 직전 FTO 검토로 인해 회피설계 비용이 커질 수 있다.
- Claim Chart의 근거 도면/BOM/시험성적서가 버전별로 재현되지 않는다.
- 법무 검토, Gate 승인, 모니터링 상태가 프로젝트 관리와 분리된다.

### 목표
1. G0~G8 특허 Gate를 개발 프로세스에 내재화
2. Feature–Patent–Claim–Evidence–Risk–Decision의 디지털 추적성 확보
3. 설계 Rev/ECO 변경 시 IP 재검토 자동 트리거
4. AI 보조로 후보 특허 선별·요약·초안 생산성 향상
5. 최종 FTO 판단은 전문가 승인으로 통제

### In-Scope
- 프로젝트/제품/Feature Tree
- 특허·패밀리·권리상태 수집/등록
- 검색식/검색결과/Long List
- Claim Chart
- 설계회피안 및 비교
- Evidence(도면/BOM/시험자료) 버전관리
- FTO Risk score/등급
- G0~G8 Gate/승인
- ECO/ECN 영향 재검토
- Watch/모니터링
- 대시보드/KPI
- AI/RAG 보조
- 감사로그/RBAC

### Out-of-Scope
- 법률의견 자동 확정
- 특허청 출원 대리 업무
- CAD/PLM 자체 기능 전체 대체
- 소송 전략 자동 결정

### KPI
- 검토 커버리지 ≥ 95%
- Claim Chart 완료율 ≥ 95%
- 출시 전 미승인 Critical/High = 0
- IP 영향 설계변경 재검토율 = 100%
- Gate 승인 리드타임 30% 단축(기준선 확인 필요)
- 핵심 특허 신규 공지→평가 리드타임 50% 단축(기준선 확인 필요)

## 6. 예외·제약·위험
- 특허 법적 상태와 청구항 해석의 최신성은 외부 데이터 품질에 의존한다.
- AI 결과는 법률 의견이 아니며 반드시 출처와 원문 확인이 필요하다.
- 국가별 법리 차이는 전문가 검토 대상으로 분리한다.
